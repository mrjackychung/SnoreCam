# SnoreCam

用 Android Studio (Koala 以上) 打开本目录 → 等 Gradle 同步 → 插手机运行。
首次打开会自动生成 gradle wrapper。需要 Android 8.0+。

## 睡前听音乐
首页可设「延迟开始检测」(30/45/60 分钟或自定义),延迟期间不开麦克风、不录像,时间到自动开始;也可在监测面板点「立即开始检测」。

## 使用
1. 睡前接充电器,手机立在床头,后摄对着自己,点「开始监测」,屏幕随即变黑。
2. 鼾声出现 → 屏幕微亮并显示声轨,30 秒内 2 次鼾声 → 自动录 1 分钟视频。
3. 早上点屏幕 → 停止监测 → 「查看记录」,看视频判断姿势,标记侧睡/仰睡,顶部自动汇总两种姿势的 dB。

视频和声轨数据(.mp4 + .mp4.json)存放:Android/data/com.example.snorecam/files/Movies/

## 前置摄像头 + 屏幕补光
控制页选「前置」后,开始录像时屏幕从黑色按平方曲线慢慢变成暖白,亮度渐增到你设的上限(默认 30%,25 秒),录完约 2 秒内熄灭。亮度上限和渐亮时长都可调。
