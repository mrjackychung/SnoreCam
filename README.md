# SnoreCam

用 Android Studio (Koala 以上) 打开本目录 → 等 Gradle 同步 → 插手机运行。
首次打开会自动生成 gradle wrapper。需要 Android 8.0+。

## 使用
1. 睡前接充电器,手机立在床头,后摄对着自己,点「开始监测」,屏幕随即变黑。
2. 鼾声出现 → 屏幕微亮并显示声轨,30 秒内 2 次鼾声 → 自动录 1 分钟视频。
3. 早上点屏幕 → 停止监测 → 「查看记录」,看视频判断姿势,标记侧睡/仰睡,顶部自动汇总两种姿势的 dB。

视频存放:Android/data/com.example.snorecam/files/Movies/
